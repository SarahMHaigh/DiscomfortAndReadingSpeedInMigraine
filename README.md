# Discomfort and Reading Speed in Migraine

Stimuli and data from 112 participants who read high and low autocorrelation texts superimposed on chromatic gratings that differed in their color difference. From paper:
Sarah M Haigh & Isabella M Durda (accepted). Discomfort and reading speed: Effects of migraine. Perception. https://doi.org/10.1177/03010066261442090. 

RoR_Git.xlsx header information:
- Name = participant ID
- ID = numeric ID
- Headache = original cateogory
- Migraine = neater category
- Aura = participants with migraine with aura
- MigraineAura = neater aura category
- PG = number of illusions reported in the Pattern Glare Test
- PGgroup = if PG>1 then in the high PG group (coded 1), otherwise in the low PG group (coded 0)
- HeadInjury = category for history of mild traumatic brain injury or control
- Significant head/neck injury/concussion = participant's initial response in the demographics survey
- Describe what happened = more details on the head injury
- Type = speed
- Age = in years
- Gender = demographics
- CD = color difference: S=small; M1=mid-small; M2=mid-large; L=large
- Pair = color paid: P=purple or red-blue; T=turquoise or green-blue; Y=yellow or red-green
- RoR = text type: N=non-stripy; S=stripy
- Chrom = chromaticity difference in CIE UCS space
- Order = presentation order regardless of stimulus
- Half = before (1) or after (2) break
- Speed = reading speed (the dependent variable)

AoA_RoRtests.xlsx = age of acquisition information
